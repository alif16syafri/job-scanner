# Dashboard design

Glassdoor and Mercor informed the desktop layout: filters above a compact results list, with the selected job beside it. The detail panel shows the match reasons, eligibility checks, source dates, and a link to the employer listing. Narrow screens show the list first and provide Back from the selected job.

Blue marks selection and listing links. Amber marks items to check. Consistent row heights and tabular scores support comparison. Source health sits above the results in a disclosure so scan gaps are visible without taking over the list.

References: [Glassdoor](https://mobbin.com/screens/b3c0eea2-d650-4faf-b589-1891c3ffb24d) and [Mercor](https://mobbin.com/screens/db3c0878-3d38-4b6c-a469-c9c776872bef).
